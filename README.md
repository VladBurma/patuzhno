# патужно — «Станція» для Oukitel P2001 Plus

Програма для macOS (іконка в рядку меню), яка показує стан зарядної станції Oukitel, графік відключень Yasno по вашій групі, веде історію, стежить за батареєю, вмикає/вимикає розетки й шле сповіщення в Telegram, коли світло зникає чи з'являється.

Кожен користувач піднімає **свій** безкоштовний сервер на Cloudflare і **свого** Telegram-бота — дані зі станції нікуди більше не йдуть.

## Що потрібно

- Mac з macOS 13+ і Xcode Command Line Tools (`xcode-select --install`).
- Станція Oukitel, підключена до Wi-Fi і додана в застосунок **Wonderfree** (той самий акаунт — email і пароль — вводяться в програмі один раз; пароль не зберігається, лише ключ сесії).
- Для хмари, Telegram і панелі на телефоні (необов'язково): безкоштовний акаунт [Cloudflare](https://dash.cloudflare.com) і Telegram-бот від [@BotFather](https://t.me/BotFather).

Перевірено на Oukitel P2001 Plus (2048 Вт·год). Інші моделі Oukitel з тією ж хмарою (P5000, P1201, P800…) мають працювати, але не перевірялись.

## Встановлення

### 1. Сервер (необов'язково, ~10 хвилин)

Без сервера програма працює лише вдома по Wi-Fi: показує стан, графік, керує розетками. Сервер додає: дані й керування з будь-якого місця, панель на телефоні, Telegram-сповіщення, збір історії навіть коли ноут вимкнений.

1. У Cloudflare: **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers»**. Скопіюйте токен і **Account ID** (видно на головній сторінці dash).
2. У Telegram: напишіть **@BotFather → /newbot**, задайте назву і username бота (наприклад `my_station_bot`). Скопіюйте токен.
3. У Терміналі:
   ```bash
   cd cloud
   ./deploy.sh
   ```
   Скрипт спитає Account ID, API-токен, токен бота та ім'я бота, створить базу й сервер, підключить бота і запише адресу сервера у `server.url`. Дані для повторних запусків збережуться в `cloud/.env` (цей файл у `.gitignore`).

Повторний запуск `./deploy.sh` просто оновлює код сервера.

### 2. Програма

Двічі клацніть `build_app.command` (або `./build_app.command` у Терміналі). Програма збереться, встановиться в `/Applications/Станція.app` і запуститься. У рядку меню з'явиться іконка; при першому запуску відкриється вікно налаштування:

1. **Вхід у Wonderfree** — email і пароль від акаунта, де додана станція. Прапорець «Хмара й Telegram» видно лише якщо вказано `server.url`.
2. **Станція** — обирається автоматично; перевірте ємність батареї.
3. **Група відключень** — регіон і адреса для графіка Yasno.

Правий клік по іконці в рядку меню: Telegram-сповіщення, панель на телефоні (QR-код), повторний вхід, автозапуск, вихід з акаунта.

Якщо вдома програма пише «через хмару», дайте їй доступ до локальної мережі: **Системні параметри → Приватність і безпека → Локальна мережа → Станція**.

## Як це влаштовано

```
app/                 програма для macOS (Swift, без Xcode-проєкту — збирається swiftc)
  Core.swift         файли, журнал, локальний протокол станції (кадри AA AA, TTLV, AES-CBC), пошук у мережі (UDP 6606)
  Engine.swift       стан, історія, графік Yasno, розрахунки, вбудований HTTP-сервер (localhost:8765)
  Setup.swift        вхід у Wonderfree, вибір станції та групи
  Health.swift       стан батареї: цикли, знос, поради
  Cloud.swift        робота через сервер, коли станції немає в мережі; дозаповнення історії
  main.swift         іконка в рядку меню, попап і вікно дашборду (WKWebView)
  panel.html         компактна панель (попап і телефон)
  dashboard.html     повний дашборд із вкладками та налаштуванням
cloud/
  worker.js          сервер: Cloudflare Worker + D1. Щохвилини читає станції через хмару Wonderfree,
                     пише історію, тягне графіки Yasno, шле сповіщення в Telegram, віддає панель на телефон
  deploy.sh          розгортання сервера одним скриптом
build_app.command    збірка й встановлення програми
```

- Вдома програма читає станцію напряму по Wi-Fi (TCP 6607, протокол Quectel TTLV, шифрування ключем станції з Wonderfree). Поза домом — через свій сервер.
- Сервер зберігає лише ключ сесії Wonderfree (не пароль), виміри станції й налаштування. Вихід з акаунта в програмі видаляє все з сервера.
- Ліміти безкоштовного Cloudflare (10 мс CPU на запуск, 5 млн читань D1 на день) вистачає на кілька станцій на одному сервері.

## Безпека

- `server.url`, `cloud/.env`, `build.log` не потрапляють у git (`.gitignore`). Не публікуйте токени Cloudflare і бота.
- Ключі станції й сесії лежать у `~/Library/Application Support/Станція/` з правами тільки для вашого користувача.
